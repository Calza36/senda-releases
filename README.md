# Senda

Aprende sistemas y DevOps desde cero: lecciones por pasos con animaciones, prácticas en una terminal real y un tutor que te ayuda a pensar.

Este repositorio solo contiene los instaladores. Descarga el último desde [Releases](https://github.com/Calza36/senda-releases/releases/latest) (`Senda-Setup-x.y.z.exe`, Windows 10/11).

- Al instalar, Windows puede avisar porque el instalador no está firmado: «Más información» → «Ejecutar de todas formas».
- La app se actualiza sola cuando hay una versión nueva.
- Para el tutor, pon en Ajustes una clave de una API compatible con OpenAI (por ejemplo DeepSeek).
- Las prácticas con terminal necesitan Docker Desktop.
- Tus datos se guardan solo en tu ordenador, en `%APPDATA%\Senda`.
